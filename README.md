# SYNVORA OS — All-in-One Business & Social Commerce Platform

Official full-stack repository for **SYNVORA OS** by [Synvora IT](https://www.synvorait.com/).

## Tech Stack
- **Frontend:** Next.js 16.4 (App Router + Turbopack), React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Recharts (Light & Dark Mode enabled)
- **Backend:** Python 3.13, Django 6.1.2, Django REST Framework
- **Database:** Neon Cloud PostgreSQL 17 (AWS Singapore)
